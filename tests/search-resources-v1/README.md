# 真实词条资源探针 v1

本表为项目在看新词库实验结果前冻结的24条资源输入，没有gold，不是正式train/dev/heldout。使用真实授权词条快照运行，但输入本身仍为人工压力探针，不能报告语言准确率。保留空、前缀、撇号等待、非法、长歧义及未命中项。多条同家族变体只作结构对照，不作为独立质量样本。

协议及正式质量目标在[预登记](../../docs/cl008-real-resource-protocol.md)，入口为`python scripts/evaluate_real_lexicon.py --evidence <已审核数据证据JSON>`。没有合法词库时不会自动填充合成词条或旧64条资源。评估输出包含全部输入、每配置候选/路径/特征、原始延迟样本、显式预算、逐例新增/丢失/名次变化及数据指纹。

人工输入表采用项目MIT；被测词库和输出候选正文继承各上游数据许可证，不因本表MIT而重新授权。
