# Round 26 统一离线 Worker 适配约定

## 请求与生存周期

现有 IPC 保持版本 1，`cloudleaf-translation` 依赖轻量 IPC，IPC 和输入 DLL 继续不依赖翻译执行库、联网运行时或权重实现。现成的 TranslationService 后台队列提交给 WorkerProvider，适配器自身不另建任务调度器。一个适配器独占一个受监督的 WorkerClient，至多一条本地阻塞送译，历次请求共享子进程与同方向热模型。

后台线程将方向、源文本与现有会话/代次/输入修订送到 WorkerClient，等待已核对 generation、请求、任务、模型目录、方向与结果版本的终态。服务继续保有外层任务身份和取消权。观察句柄仅持有短时状态快照，使用 try_lock，供窗口和输入宿主读进度。快照记录本机进程、明确阶段、请求键、源与输出 SHA-256、模型及测量，避开原文与译文。生成译文仍以 Generated 展示，模型资产仍限本地研究。面板原 Word/Phrase/Sentence 选择沿用，三种在现有 Worker 中均使用同一整句推理。

离线路径构造时不读模型或启动。遗留仅路径的面板配置可由 Setup 背景线程读取至多 64 KiB 的 catalog 计算身份。Bridge 使用原命令行的固定 SHA，适配器在后台区分 catalog 缺失/不符和 Worker 模型校验错误。权重及模型 manifest 的校验和推理由 Worker 执行。缺少模型与授权配置时不得切换网络或本机推理。

取消时立刻转发已有取消或超时意图，交互或过期任务均不被重放。旧进程的回收仍用现有 IPC 监督器，重启由后续显式请求触发。服务在关闭队列、后台任务结束后调用 provider 的有界收尾。UI 或按键线程只发取消/停止接单，不等待。换配置须先确认旧服务线程结束及子进程可回收。无法确认旧进程退出时报告失败。各进程各管一个子进程及一份方向模型，无全局共享进程。

## Bridge 与验证

以同一 WorkerProvider 替换仅有 CLI 使用的 LazyMarian，移除 Bridge 对模型计算 crate 的依赖。保留输入参数、JSONL 原字段和提交三态，兼容追加 Worker 元数据及完整性提示字段。复用已有完整性规则，并保持原始译文、显式确认、过期拒绝、原文回退及不学习。检查模板、普通输入、双向实际模型、热复用、方向切换、取消、退出后新代及损坏/缺失资源。源码、哈希及非文本原始证据绑定实际精确提交；原始研究数据及翻译只保留 Git 外。
