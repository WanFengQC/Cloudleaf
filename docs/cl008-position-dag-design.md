# CL-008 无历史评分的精确状态压缩实验

2026-10-22，先提交设计及真实规模旧方法证据，再实现。此项由资源探针暴露的计算机制驱动，不使用正式heldout，不更改默认输入核心或现有ExactDag。

## 触发证据与范围

完整44,431条Unicode17单字词条、24条无gold探针、固定预算与Structural评分下，原ExactDag在11条探针触发200,000扩展限额，仅8条有候选；最大单例P95约284.49ms、P99约318.19ms。Reference自身15条触预算，只有7条可完整配对，其中空/等待/未命中也包含在内；这7条一致不代表全体无损。完整逐例、原始样本及指纹见`reports/cl008-real/unihan-before.json`。所有频率unknown，不存在语言质量结论。

当前DP用`(位置,最后词条)`作为通用一阶状态。在Structural/Weighted中，下一个词条的分数与之前的最后词条无关；这些状态存在冗余。新增显式`Method::PositionDag`，仅对这两种评分可用，其他评分返回InvalidConfig，不能静默换算法。Reference、ExactDag、Beam、原输入引擎及旧机械模型原样保留。

## 等价条件与打平

新方法每个位置保留k个不同前缀文本，同文本取分数最佳且ID序列最小的路径。由相同位置可接的后缀集合相同，Structural/Weighted的后缀增分相同。对任一被舍弃的第k+1个不同前缀文本与后缀，其前k个不同文本都能接同一后缀，追加同一字符串保持不同，因此舍弃者不能独占unique top-k。

平局继续比较完整稳定词条ID序列。每个词条读音非空，图边具有正长度；同一位置的路径不可能是另一条路径的严格ID前缀。Prefix边仅能到输入终点，不能在中段为同一词条ID制造另一种长度后再追加词条。追加公共后缀不能改变既有ID序列先后。保留的代表路径及各加法特征与Reference一致。不得按输出文本字典序打平，因为追加后缀可能反转这种顺序。

评分没有饱和算术：公开输入硬上界512字母，正长度边最多512词；每词结构代价-100，末尾最多一个Prefix额外-300。频率是u32，`floor(log2(frequency+1))`最大32，每词加权最多320。因此Structural/Weighted总分绝对值小于220,000，频率特征和缺失/词数计数同样有界，远小于i64/usize边界。受支持评分的加法和比较不会因溢出或饱和改变等价证明；新评分或长度硬上界改变需要重新论证。

以上只证明当前同图、无历史且可加评分、无预算截断的unique top-k。Bigram/ContextRerank依赖上个词条，不能使用这份压缩证明；后续评分新增非局部特征时必须再审查。前缀边和撇号边界继续由相同Lattice决定，不在新搜索内改图或拼写。

## 工作量与回退语义

默认预算不变。按拓扑位置处理`Vec<Path>`，合并到终点的共享k-best容器；所有未处理批次、当前路径、最终候选和临时克隆仍计入驻留路径数。扩展前先计费，创建临时路径前检查`resident+1`，去重截断后再更新计数；不能仅把最终k计作内存。路径计数仍不等于字节内存，另测独立进程峰值。

图边/扩展/驻留触限继续有原因和`guaranteed=false`；保持原ExactDag耗尽时空结果及完整原文回退语义。没有静默扩大预算，也不将更快但被裁剪的输出标为精确。旧方法仍作为可回退对照。

## 先行门禁与对照

1. 在既有小图/固定seed机械输入上，Structural/Weighted、k=1/3/5，PositionDag与完整Reference逐项比较文本、分数、ID序列及特征。包含同文多切分、ID平局、前缀、显式边界、Unicode偏移、无解与等待；原Exact测试不删除。
2. Bigram/ContextRerank显式拒绝；最小边/扩展/驻留预算、驻留瞬时峰值与工作量触发回退测试保留。
3. 同一完整真实词库/24探针，保留旧8种资源配置，再增加PositionDag标准及edge128/expansions500/resident128四项。输入、词库、评分、k、预热、样本数和限额不调参。
4. 在Reference或旧Exact无预算截断时，逐项完整结果必须相同；两者皆不完整时只能报告新增可用输出和工作量，不能声称已独立证明全空间正确。
5. 记录每例候选/路径/特征、增删/名次、预算、原始延迟样本及峰值。旧资源结果不覆盖；固定新实现后整套旧机械/事件/资源检查及双平台CI重跑。

语言准确率、真实词频/训练模型、多字词覆盖、纠错/方案/学习/增量及平台接入仍未完成。即使精确压缩有资源收益，也不等于最终算法最优或CL-008完成。
