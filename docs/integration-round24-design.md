## 两种召回与资源合同

- 分池交错方案在同一张图上调用原精确字符、词汇和结构搜索。按 65%、25%、10% 分配 200,000 展开次数。串行执行，各阶段从 50,000 活路径额度扣除仍驻留的结果。先按字符、词汇、结构顺序轮流取出各源下一条，按正文去重并记录来源排名与路径代表。单源截断及超预算显式保留。最终独立正文最多 50 条，交错集合不具备某一评分的全局最优保证。
- 上下文束搜索复用字符路径分和拼音解释约束，在每条边上增加可信词语转移收益。对新词表面及缺乏直接支持的转移无需分配虚构词频。固定门槛：至少两次观察，收益为词二元定点 log 概率减去平滑词一元 log 概率，截断到 0 至 1024（1 比特）。BOS/EOS 同样计入。累计字符对数和收益，不按词元个数归一。比较顺序沿用拼音解释成本、可信用户偏好、分数、稳定 ID 和解释边。每字节位置最多保留 64 条前缀，状态保留路径、前词和前字符。正文相同的不同分段不在完成前合并。完成时同正文的全序最佳路径参加 Top-K 去重，实时去重结果独立于参考保证。
- 两方案使用相同输入长度及图边限制，活路径和展开均计量。取消或边界失败保留既有原文或错误语义。记录被剪前缀、丢失正文和各源预算。小图用无束剪枝、不同顺序的穷举完整边路径，经相同评分定义和独立排序对照正文、路径、分数与顺序。参考限额耗尽视为未证明。生产路径无入口改动。
