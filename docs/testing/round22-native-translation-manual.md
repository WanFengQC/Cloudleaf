# Round 22 原生翻译人工验收

执行状态为 `not-run/user-paused`。下列步骤供隔离宿主人工作业，原生窗口代码和无窗口测试无法证明实际桌面交互结果。

## 准备

使用对应提交的 Windows 集成包，把 `cloudleaf-translation-worker.exe` 与 `cloudleaf-ime.exe` 保留在同一可信发布目录。准备实际核验的 `runtime.tsv` 和 SHA-256，以及已有开发许可的模型目录和 SHA-256。工作进程不读取其他应用，也不触发系统输入法注册。测试词库请使用独立的合成档案。所有内容使用专门测试文字。

```powershell
.\cloudleaf-ime.exe --interactive-input-host RUNTIME_TSV RUNTIME_SHA --translation-catalog CATALOG_JSON CATALOG_SHA
```

默认使用 1 个推理线程。可通过 `--translation-threads 1|2|4` 选择。需要测试专有名词时追加 `--translation-glossary GLOSSARY_TSV`。术语内容与用户拼音词库独立，格式见完整性说明。以下操作只在“云笺 · 隔离输入与翻译”宿主自己的文档和编辑控件上验收。

| 序号 | 操作 | 预期 | 实际 |
| ---: | --- | --- | --- |
| 1 | 用上述命令启动隔离宿主 | 显示普通输入、英文缓冲区和显式翻译控件。宿主空闲时无工作进程 | `not-run/user-paused` |
| 2 | 焦点置于宿主，键入 `nihao` | 真实拼音候选可用。Space、数字、Enter、Escape 和 F6–F8 沿用原行为 | `not-run/user-paused` |
| 3 | 用方向键高亮“你好” | 保留拼音和候选，宿主文档尚未写入 | `not-run/user-paused` |
| 4 | 点击“翻译高亮候选 → 英文” | 本地工作进程按需启动并显示阶段。原文与预览分别可见，当前文档未改 | `not-run/user-paused` |
| 5 | 推理期间继续键入拼音 | 输入照常更新，旧译文不能覆盖新组合 | `not-run/user-paused` |
| 6 | 重新发起后点击“取消翻译” | 停止当前任务，原文保留，无上屏动作 | `not-run/user-paused` |
| 7 | 发起后切换到批准的空白验证窗口，再回宿主 | 旧结果不可确认。再次发起到只读预览内部移动焦点时不丢候选。进入词库面板取消译文，保留当前组合 | `not-run/user-paused` |
| 8 | 翻译就绪后点击“确认译文上屏” | 在本宿主文档仅写一次，未先写中文。普通选词仍只提交普通候选 | `not-run/user-paused` |
| 9 | 在英文缓冲区输入测试句，选择“翻译缓冲区 → 中文”。分别试取消、保留、清空、提交英文原文、确认译文 | 编辑仅改变本窗口英文缓冲区。确认才写文档，已提交英文缓冲区清空 | `not-run/user-paused` |

| 11 | 用明确缺失的专用测试目录启动宿主并发起翻译 | 给出模型不可用的信息，保留原文，普通输入继续可用 | `not-run/user-paused` |
| 12 | 根据隔离测试计划确认并结束本次实际创建的测试 worker，然后继续输入和显式重发 | 原文保留，普通输入继续。下次显式命令尝试启动新一代工作进程 | `not-run/user-paused` |
| 13 | 在合成用户词库开启学习，添加、使用和删除测试词 | 编辑、持久化、索引发布及可信 Applied 学习仍符合原契约 | `not-run/user-paused` |
| 14 | 记录一次普通选词学习计数，再做译文提交 | 译文提交不增加本地学习统计 | `not-run/user-paused` |
| 15 | 启用“下一次提交注入Unknown”，确认预览，核对文档后开始新会话 | 文档可能已应用一次，保留核对材料，原任务不可重试或补写 | `not-run/user-paused` |
| 16 | 在一次任务运行中关闭窗口，核对本次专用进程状态 | 宿主先关闭接收，专用工作进程经有界退出流程回收，不影响其他进程 | `not-run/user-paused` |
