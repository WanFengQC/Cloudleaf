# CL-008 真实词条搜索实验与正式评估预登记 v1

2026-10-22，先提交本协议，再实现工具和查看新实验结果。承接 `algorithm-design.md`、`algorithm-evaluation.md` 与 `cl008-design.md`。默认输入引擎和旧64/41/83条回归保持不变；本实验不是CL-010集成。

## 本轮可回答的问题

以C审核许可、完成可追溯导入的完整Lexicon v2为只读快照，比较同一图、同一Structural评分下的Reference、ExactDag、Beam1/8/64，以及明确收紧的图边/扩展/驻留预算。输出整词边与全区间路径的非空候选率、词条格大小、搜索差异、剪枝原因、延迟及独立进程峰值。完整词典载入，不按本轮输入筛选词库。

本轮输入是项目预先登记的**资源探针**，没有gold，不是train/dev/heldout。输入不从词典批量生成；任何后续词典读音抽样只能另标`dictionary_derived_probe`，不能转成独立正确答案。所有探针含OOV、空串、非法、等待和超限项均保留在分母。非空候选率不叫准确率；多词条可拼接不叫语言正确或成熟整句理解。

unknown频率保持None且词频特征关闭；本轮统一Structural，不训练Bigram，不把人工词频或词条行序当统计。没有授权训练/评估语料，频率、语言模型、Top-1/5、MRR、纠错及上下文质量均为null/无结论。旧机械实验继续独立运行。

## 固定对照与预算

所有策略output_k=5，输入上限512字节/256字母，不修改库默认值。标准图边16384、扩展200000、驻留50000；Reference同预算，只在未触预算时作为完整穷举参照。ExactDag与Reference均未触预算时，候选文本、分数、词条ID路径和特征必须逐项相同，否则工具非零退出且保留失败报告。参考穷举耗尽不能被标为Exact正确性的证据。

Beam宽度1/8/64使用同图同评分，宽度不是生产默认结论；单列Beam剪枝和工作预算触发。另固定ExactDag三项压力配置：图边128、扩展500、驻留128，每次只改一项。它们是故障/资源探针，不是根据heldout选出的合理产品预算。

“整词边”对照仅取从0到输入终点的一条边，按相同结构代价及稳定ID排序。它不是旧64条引擎在v2上的兼容实现，不冒充其准确率。逐例记录与整词边/标准ExactDag/完整Reference相比新增、丢失、顺序/名次变化；预算触发时仅记录可观察原因，不能断言某条路径由哪一次剪枝丢失。

每配置在独立release进程中载入全词典，默认预热5次、每例测量30次；计时包括规范化、建图和搜索，词典读盘/建索引另列冷加载。保留原始样本ns数组、P50/P95/P99/max、进程峰值及采集方法。预先固定的短词/短句工程目标P95≤5ms、P99≤10ms仅作为诊断，不据此宣布真实TSF或产品达标。背景负载未控制，不能只看耗时顺序宣称最优。

## 数据及产物契约

工具接受C的runtime.tsv及外部证据描述JSON，证据含runtime SHA-256、逐项来源标识、上游版本/URL、许可证/许可正文路径及SHA、导入报告路径及SHA。工具核对文件指纹、记录数、v2来源/原始记录/许可映射，不接受未登记来源、synthetic、manual或无许可材料。检查只验证所提供证据一致性，不能代替C的人工作权审核。原始数据和许可证不自动上传或重新授权；外部路径只在本地完整报告中保存。

Rust独立宿主只预载Lexicon和读探针，搜索时不I/O、不网络、不Python；Python负责证据检查、独立进程资源采集、差分和报告。失败、无候选、等待、输入拒绝、预算耗尽和无法证明参照均显式列出。源/二进制/词库/探针/协议指纹、提交、完整配置与命令进入报告。受限数据缺失时工具先完成自测，报告阻塞，不造数替代。

修改范围：新增`examples/resource_probe.rs`、`scripts/evaluate_real_lexicon.py`、`tests/test_real_lexicon_evaluation.py`、`tests/search-resources-v1/**`、独立资源审计登记和报告；不改搜索算法及默认输入核心。需要改变算法或加载契约时另先提交设计。

## 正式语言评估的预登记门禁

本节是未来正式集冻结前的工程目标，不表示当前已有数据或已经验收：

- 数据必须有可分发或明确评估授权的来源、匿名化规则、原文/拼音/接受答案与意图标注，至少覆盖词、短句、长串、同音歧义、专名/OOV、混输及正确输入控制。禁止由待测词典自生成gold。
- 按上游文档/意图及所有拼音、前缀、错字变体的共同家族分组。家族级70/15/15划分train/dev/heldout，同一规范输入跨split必须人工复核并默认拒绝。先提交家族清单及各split哈希；分配脚本/固定seed一并冻结。训练代码只能读取train，选择权重/预算只能读取dev。
- heldout至少2000个独立家族；样本量、来源分层配额和排除规则须在第一次打开heldout前提交。新增未见heldout，不把旧83 seed当盲测。由独立保管者交付封存文件；同一heldout只做一次预登记发布比较，观察后调整必须增加实验版本并使用新封存集。
- 暂定产品质量目标：总体Top-1≥90%、Top-5≥97%、MRR@5≥0.92；相对冻结基线Top-1配对差异95%置信区间下界≥-0.5个百分点，任一预登记主要来源组退化不超过1个百分点。阈值是预先提出的工程要求，没有现有正式集支持；若不合理必须在heldout不可见阶段通过新协议更改，不能看结果后降低。
- 对家族进行10000次固定seed配对bootstrap给95%区间，同时公开改善/退步/持平计数及所有OOV/空结果/拒绝样本。目标未满足或样本/授权不足即不放行，不只报告IV。
- 语言模型额外需要授权训练语料、频率量纲、时间/来源、未知值规则、模型/参数哈希及训练可复现。独立评估/隐私/学习关闭、回退、P95/P99和内存预算同时验收。

本轮正式集、训练语料、统计词频和生产模型均缺，以上语言目标状态为**未评估**。真实词条资源实验只能解除搜索规模/一致性的部分未知，CL-008退出条件和CL-010依赖保持未满足。
