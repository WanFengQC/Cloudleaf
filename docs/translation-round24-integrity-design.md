# Round 24 离线翻译评测与文字完整性约定

固定 Marian 中英双向权重、单线程和现有 worker 协议。本轮先冻结自编研发输入与控制译文，再使用真实模型执行双向推理。逐条记录原文、原始译文、模型与目录身份、生成步数、可信截断状态及阶段时间。模型生成与规则检查分别计数，预设控制译文只用于测试规则。正式质量需要独立双语审读。

完整性检查增加四类 ASCII 标识及一类显式否定提示。HTTP(S) URL、有限扩展名的文件名、带 `v` 的三段版本号、带连字符的型号形状按原始字面值和出现次数检查。类型与范围在 UTF-8 原始文本上确定。URL 和文件名中的数字归该标识，同一段文本只提取一次。没有完整配对时使用现有缺失、变化或无法确认状态。文件名扩展名范围、版本和型号的字形边界须有定向回归。

否定检查限于句首 `Do not`、`Don't`、`Please do not`、`Please don't`、`请勿`、`请不要`、`勿` 与 `禁止` 这类命令式提示。提示数不同时要求人工复核。提示数相同仍可能发生角色互换、否定范围变化和双重否定。大小关系与数字对对象的绑定留给原文和原始译文对照。所有新结果继续使用现有确认事务和原始译文，术语查找与候选注释沿用现有实现。

新模型选型仅查询上游发布页、许可证和文件元数据，经当前授权的开发权重仍是固定 Marian 一对。新增模型的权重获取、量化、推理、实测占用和发布各自需要可核验的原件及审批。后端接入通过 worker 维持现有隐私和生命周期边界。
