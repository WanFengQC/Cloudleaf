# CL-008：全输入词条格与可重放搜索设计

本文件先于实现提交。分支 `codex/cl008-search`，共同设计基线 `c085601`；不修改或替换既有拼音、词典、候选、输入状态机。CL-008的正式语言质量退出条件尚未满足，本轮建设可验证的搜索、评分及实验基础。

## 1. 模块和输入边界

新增 `cloudleaf-search`，仅依赖已审查的workspace基础crate。`Lexicon`在宿主载入时解析TSV和建立读音Trie；同步搜索不读文件、不联网、不加载模型。兼容旧v1（frequency明确标manual）与[Lexicon v2](lexicon-v2.md)，unknown必须空值且禁用词频观测特征。来源、原始记录、许可和nullable频率随词条保留。

规范化独立于原型32条解析：保留原文，ASCII大小写归一，`ü/Ü`转换为键盘`v`并保留UTF-8位置映射；撇号是必须满足的音节边界。非法字符、连续/前导撇号和超限返回明确状态；尾部撇号等待后续音节。新功能不自动改变原型输入行为。

词条图直接从原文区间匹配读音。顶点为规范字母偏移，边有原文UTF-8覆盖、词条ID和完整/末音节前缀类型；前缀只允许在输入末尾，且不能补出多个尚未输入的音节。任何完整候选路径必须从0覆盖至全部有效输入终点。未知片段不被悄悄丢弃；没有全覆盖路径时返回完整原文回退，不伪装成中文候选。

## 2. 同图、同评分的搜索对照

DAG是表示，DP是算法，不把二者包装成互斥的算法名称。

| 方法 | 定义 | 可证明范围 |
|---|---|---|
| Reference | 小图穷举所有完整路径，预算未触发时排序、文本去重取k | 作为独立参考，不用于长串生产承诺 |
| ExactDag | 拓扑动态规划，状态含位置及上一个词条/语言模型状态 | 一阶评分、确定性比较、预算未触发时应与Reference逐项相同 |
| Beam | 每个位置全局保留有界假设，再扩展 | 有损；必须报告宽度、剪枝数及与Reference/ExactDag差异 |

所有方法使用同一词条图、整数评分和候选物化。DP每个状态保留k个不同前缀文本；同一文本保留最佳路径。最终再次按文本去重，避免多个词条分段挤占unique top-k。平局按稳定词条ID序列处理，不能依赖哈希迭代或平台时间；路径顺序不依赖可能在追加后反转的输出文本字典序。

ExactDag等价依赖状态包含未来评分所需全部信息。若以后使用更长N-gram、神经状态或全局特征，先扩展状态/证明及差分测试，不沿用一阶最优保证。上下文重排仅保证已召回有限池内顺序，不是全空间最优。

## 3. 评分与模型

- Structural：显式词条数和末音节补全代价，验证结构完整性。
- Weighted：增加固定版本的整数词频特征，unknown贡献关闭并保留缺失计数；manual值仅机械对照，不当真实频率。
- Bigram：对已载入训练快照计算加一平滑一阶转移，整数定点log量化，含BOS/EOS和未知词回退；模型加载和计数在按键路径外。
- ContextRerank：先取得与Bigram相同的有限候选池，再使用显式已确认左词对首词的条件转移重排。上下文不可用/关闭时不使用，不保存输入历史。

权重在机械数据创建及新测试运行前固定，目的为验证特征/模型机制。未经正式训练/dev调参与独立语言评测，不宣称权重适用产品。训练数据与测试按家族隔离；83条旧seed已经看过，只保留回归用途，既不训练也不调参。

## 4. 资源与错误语义

配置同时限制输入字节/字母、词条图边、扩展次数、驻留路径、每状态k、Beam和输出数量。所有上限校验，预算触发给出统计/原因和`guaranteed=false`，不把部分结果当成完整无剪枝结果；原文仍可恢复。墙钟时间只用于外部测量，不决定候选集。

统计包括图边、路径扩展、驻留高水位和Beam剪枝。资源计数不冒充进程RSS；性能报告另记录独立进程峰值、构建/数据/源码/二进制指纹。内核不写日志，错误不回显输入。

## 5. 自动化与实验

1. Lexicon严格v1/v2校验、未知频率保持缺失、来源/许可标识和损坏输入。
2. 撇号边界、`ü`位置映射、末音节前缀、整句全覆盖、未知输入和长串预算。
3. 小图Reference与ExactDag的全部候选/分数/路径差分，含重复文本、歧义、平局和随机但固定种子的机械图。
4. Beam足够宽时与ExactDag一致；窄Beam的可解释丢优反例及资源预算触发，不删除失败以得通过。
5. 整数bigram和上下文确实影响路径，关闭上下文恢复同一基线；输入词频缺失时不伪造统计。
6. `evaluate_search.py`在release运行各方法/排名方案，固定预热与样本数，保存每例候选、名次、对照差异、分组及延迟/内存。

机械/合成资源全部登记MIT来源并设置 `language_accuracy_valid=false`。train/dev/test家族独立，但不是语言盲测。正式语料取得前，只报告机制正确性、覆盖和资源，不报告正式输入法准确率或算法最优。
