# Round 30 PositionDag 评分路径

在 Round 29 已经通过的固定图与预算上，满桶会在复制 `Path` 的正文和 ID 前拒收严格劣于末项的扩展。当前实现仍在每次尝试时复制并累加完整的 `Features`，即使路径稍后会被拒收。

试验将解读代价、用户偏好、总分与词汇分先算为标量。满桶沿用原借用比较，逐词条和逐弧的顺序保持一致。只有保留为待插入对象的扩展才复制并填充说明特征、正文与路径；同分留存和正文去重仍由原有桶函数处理。图、算法、方法选择、遍历顺序、时钟调用次数、预算检查与驻留统计保持原语义。显式 `Scoring` 先后仍覆盖评分键计算；延迟的说明特征归入遍历中生成路径的工作，阶段耗时仅用于诊断。

验收先添加带已知及未知词频、已观测及未观测词汇分、同文异 ID、逐弧解读与前缀成本的 Reference / PositionDag 完整候选对照，再运行既有测试和冻结重放。候选正文、分数、所有特征、词条 ID、边 ID、预算及提交证据按原分母逐项检查。独立试验只更换评分逻辑，在同一图基底上比较 release 无插桩时间、显式阶段观察和分配原始记录。收益不稳定或回归时不保留生产改动。
