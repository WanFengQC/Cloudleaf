# Round 27 简拼候选格和输入评分

基线为 `a6e48cbe28d48a010629a65537cfb6743522356a`。全拼、简拼和混合语音解释均沿用固定词典、模型、方案及现有上限。使用 171 键和 243 键的既有研发轨迹，诊断与计时分开运行。

语音解释与词典 Trie 相交时，完整音节、首字母及末尾前缀都可到达词条。当前起点的表按终点和词条合并来源，词条音节边界、解释代价和原始弧序列仍决定合法性及代表选择。首次发现下一条不同的词条边会超过上限时，旧实现跳出整个外层循环，没有发布当前起点已经合并且占用预算的边。先证明保留这些边时图能准确报告截断，仍保持原文回退。保留已完成起点的顺序，当前表仍按终点和词条索引排序，后续起点仍不会在同一预算处理。

普通相交会在词条候选和 Trie 状态中重复分配短弧序列与音节边界。用已受解释器约束的弧索引和内联的词条边界表示相同状态。词条映射只执行一次查询。按同一组输入核对结果、顺序、来源、身份及统计。只允许有明确 GraphEdges 诊断的案例出现预期的部分图计数变化，所有其他诊断和完整结果必须保持。已触顶的图只能作为研发差分。输入核心继续沿用其预算处理。

先区分达到上限、丢弃边、保留边、完整路径和已标注目标。诊断记录字典端点命中、边界过滤、合并的来源、真正被拒的首条新边、当时已收集的边，以及入图后可参与完整路径的边。触顶时的计数仅覆盖实际处理的区间。已触顶且没有任何边到达末端的解释图不可能给出完整路径，可保持 GraphEdges 和原文并跳过必为空的搜索。具有末端边的图仍按原搜索处理。研发可用旧配置与显式更宽预算对照，但不会改变产品配置，也不将无目标的按键标为未召回。

默认 lexical 路径继续使用固定排序。无编辑的 PositionDag 只有同一位置的无历史桶，可以直接走已验证的连续位置数组。命中词条仍用其解释代价、可信用户优先级、原评分及逐弧次序比较。任何可合法使用编辑的图继续通过独立编辑量分桶。输入按键不增加磁盘、网络或线程操作。性能测量不得以扩大边、展开或驻留预算为代价。
