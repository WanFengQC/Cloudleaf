# Round 26 独立翻译面板 Worker 迁移

独立面板沿用设置后台线程、提供者注册、翻译服务和控制器。离线整句分支改用与 Bridge 共用的 WorkerClient 提供者。设置准备只读取有界 catalog 做 SHA-256 绑定，按翻译请求启动同目录 Worker。验证权重、模型加载和计算留在子进程。同一面板只持有一份活动服务和一个受监督 Worker。更换设置和关闭沿用先取消旧任务、确认后台退出的控制流。

设置文件保持原版本及缺省行为。固定本机 catalog 路径与现有词典路径和在线模型分别管理。Worker 默认单线程、正常调度。面板状态从 Worker 状态和请求进度得到，保留发起前、启动、验证、加载、就绪、推理、取消、失败和关闭语义。在控制器已有任务与结果版本校验通过后，用与隔离宿主相同的规则生成风险摘要，原译文和已有复制语义保持。

设置 JSON 可选填 `offline_glossary` 本地 TSV 路径，供离线请求检查显式术语。旧设置省略该字段会继续执行内置规则。设置线程按同一词表格式和大小上限载入，无法读取或校验时提示修复设置。仅报告风险，不改写模型输出。

无窗口 Release 探针通过面板设置仓库、设置后台线程和控制器运行真实双向任务，检测启动、热复用、方向切换、取消、结果身份及关闭后的进程状态。另用暂存设置和小型失效原件检查模型缺失或无效。逐例输入与译文仅输出到本地证据目录。此项保持现有桌面人工验收状态。
