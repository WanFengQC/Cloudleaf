# Round 29 简拼召回设计

沿用 Round 28 的边 16,384、展开 200,000 和驻留路径 50,000。每个起点内部先按合法规范音节边界匹配，词条身份仍由输入区间和词条索引共同决定。同一身份保留最小解释代价与原有弧序规则。不同读音边界、词条来源与用户身份不合并。完整图按原起点、终点和词条身份顺序发布，原搜索与排序保持。

旧策略在第 16,385 个合法唯一词条边处停止访问剩余起点。第二种策略让起点共享边容量，在原上限内淘汰已经过度占用容量的桶。第三种策略按输入末端逆向相交，并将能连接合法后缀的边优先纳入各起点份额。即使局部候选不能接到末端，也仍以原词条身份参与有界选择，不改变原文回退。只对简拼且没有需要路径累积编辑预算的情形改变触顶策略。所有图仍实际经过原有 Trie 读音与完整边界校验。任一已拒绝的唯一合法边都会报告 GraphEdges。

首次触顶后按桶大小、该桶最末选择键与原起点记录置换优先级。只更新被置换和写入的桶，避免每条溢出边重新扫描所有起点。桶内键仍依次比较后缀可达性、解释代价、消费长度和词条身份，最终发布顺序沿用旧图。后缀标记依据已探测到的合法边，受到构图访问预算约束。容量置换后必须用保留的实际边再次验证完整路径。

无纠错的 PositionDag 使用实际保留的边反向标记末端可达位置。只在使用新准入策略且实际触顶时，排除无法影响完整候选顺序的死端展开。部分边继续保留在候选图内，完整候选上限、取消点、显式触顶状态和原文回退不变。

进入输入帧的有限候选来自正常 PositionDag 完成的完整路径。该路径要求图使用后缀可达准入，且搜索返回的预算原因仍是图边截断。语言模型的研究重排及混排分段子查询沿用其既有预算回退。没有完整候选或搜索本身触顶时仍可确认原文。原始输入可继续通过显式确认提交。图边触顶诊断保留，保证位继续为 false。
