# Round 25 词典覆盖与词级评分

基础与补充词典按 Round 23 许可锁和 Round 24 原文件身份加载。用固定训练与开发片段分别统计单字、整片段和词面覆盖，读取保留的完整来源记录诊断补充词典。对相同表面与规范拼音比较重复、每写法多读音、相同读音异写法、候选歧义及图边量。音节是否可解析、已批准来源是否支持某词条和真实读音是否合适分开记录。没有获批的新来源继续阻塞。

复用已批准的两个实际语言索引及确定性切分。建立独立实验入口，对同一个精确字符 Top-50 路径同时比较其原序、词均值与新置信控制；另记录既有上下文束输出与目标代表路径。新评分沿用候选原有拼音解释成本及可信用户优先级，保留字符模型的累计固定点分数 (C)。对内部相邻词转移计算 `g=max(0,min(1024, log2 P(w|p)-log2 P(w)))`，双方均已观测且词对至少两次才计入。BOS、EOS 和未知词不计，最终增量为 `sum(g)/(2 × (正文标量数 + 1))`，最大 512 单位（0.5 比特），无法盖过超过半比特的字符路径优势。平局保留字符候选原序。该调整仅处理固定池内代表，无法恢复搜索丢失正文或同正文其他分词。旧评分导出一元均值、归一化二元均值、首尾转移、每路径观测覆盖及字符得分，检查短词/长词偏差、冷门历史和条件证据。默认输入引擎无接口接入。

离线软切分对相同已授权训练片段运行独立计数，只沿最小未覆盖字符路径分配每片段 1024 整数单位。每个位置的备选权重为已知词面在训练原文的实际重叠出现次数加一，未知单字权重为一。位置及词历史上的出流按权重、余数与稳定边顺序拆分，验证 BOS/EOS、单词与相邻转移的整数流守恒。软计数与实际观测、硬切分及生产词频分开保存，不进入 Rust reader。固定资源超限则记录退化或拒绝。

新 40 条研究验证在实现、阈值、输入锁与程序身份冻结后运行。按独立固定盐从原开发分区选择，排除 Round 16、23、24、以及已记录中文新闻的家族、ID、正文和近重复，检查与保留训练分区的交叉。选择先于词典映射，两个词典使用同一派生拼音，失败和近训练冲突保留为不支持。历史组保留可达、候选、预算和质量退化。逐例文字、拼音、原候选及软计数只在本地留证；报告使用聚合计数、分母及哈希。仍是同一权利已批准的全球来源，正式语言指标保持 null。
