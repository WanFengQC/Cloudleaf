## A：已实施及未放行边界

实现32条原生事件 FIFO、只读预判、合法单消息连发的独立序号、原生命令 barrier、实际/投影语义对照、提交三态和迟到回调隔离。两个独立监测线程以原子和无文本消息通知 STA；宿主阻塞时先检测，必须等 STA 返回才能完成隔离，不能把检测说成恢复已完成。恢复材料默认隐藏、显式查看/复制，不自动重放未知结果。

审查发现并修复两处实质缺口：空文本删除原来绕过 Writing，写后失败可能误标 NotApplied；失效后转交的旧材料原来可能被标成新 epoch，关闭旧窗口可能取消新上下文。现在删除同样在 SetText 前进入 Writing/Unknown，每个宿主外调后复核身份与监测；材料显式绑定原事件的来源 epoch。生产 COM 回归覆盖 SetText/EndComposition 失败、两处重入失焦、650ms 写入阻塞、无后续输入超时、监测失效、通知失败、重复/迟到回调及满队列。

本地126项 Rust（含66项 Windows 原生）、16项 Python、fmt、Clippy、doc、构建、资源/许可审计通过。固定 cargo-audit 0.22.2 对15个包及31份许可原件核对成功；RustSec 快照 `640bf5a9f06e66d8721e8772766531fe77c8630d`、1349条，对应锁0漏洞/0警告。该快照不保证未来依赖状态。

新 DLL 520,192字节，SHA-256 `5e7bfdcffe353af19dc887ade0ee39bebc524b5a119f4080bedce8f0ac6c999f`。实际 LoadLibrary/COM 假 manager/FreeLibrary 1次预热及20轮检查通过，进程句柄149→149，映射确实释放。另有100轮假 manager 激活/停用及 sink 失败回归。这些仅证明所测 COM/Win32 生命周期，不是系统输入法或真实应用验收。11项证据校验与 Git 实际 blob 一致，旧报告保留。

**A1–A4仍部分完成，A5未放行。** 恢复材料32批/1MiB仅限单窗口，跨已停用服务实例的有材料窗口尚无总额门禁；外部销毁恢复窗口后的材料可达性、不同线程调用 DllCanUnloadNow 时原 STA 清理，以及真实宿主长期压力仍缺证据。这些是放行阻塞，不得用空焦点装卸测试替代。记事本、浏览器、办公软件和多行编辑器均未真实验收。
