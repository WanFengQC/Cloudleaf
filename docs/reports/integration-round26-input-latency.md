# Round 26 默认 lexical 输入延迟

基线是 Round 25 最终提交 `d56ce7167b10d7ee96ff341bb27573cdfcc7a8bc`。两次独立搜索修改为 `52c99b3f1901cc81da1a1fc0348c57445d0cfecc` 和 `c929e61f386087bb88a95a77b031acfd915db77d`。输入方式、词典和排序配置继续保持。跨键缓存仍默认关闭。

## 阶段定位和改动归因

Release 全拼长串示例运行约 9.49 ms。独立诊断统计的路径遍历为 9.40 ms，其中逐边结构及词汇评分为 7.96 ms。最慢简拼示例正常运行约 32.89 ms，独立诊断中评分为 24.40 ms，方案与词典相交为 3.16 ms。各计时分别执行，评分含在遍历内，各列不可相加。

1. 词汇模型在载入时将现有观测次数与同公式计算的定点分打包为原有的 64 位值。词频/索引格式和条目大小均保持。单测逐项核对旧公式。独立对照的无探针 P95 为全拼 5.84 → 6.67 ms、简拼 27.23 → 26.61 ms。只有第一项改动时，计时显示半数场景改善，未证明稳定收益。
2. 只在 lexical PositionDag 的一次查询内，按候选格边号惰性保存评分，同一边再次求分时复用。每条边增 4 字节暂存，查询结束释放。包括零分在内与旧公式逐项一致。所有路径结构、词汇统计、未知语义、可信用户优先、输出和稳定平局保持。200,000 展开、50,000 驻留路径以及输入和图边界沿用。

| 配对项目 | 比较样本 | Round 25 / Round 26 无探针 P95 | 独立评分阶段 P95 |
| --- | ---: | ---: | ---: |
| 固定全拼查询 | 203 × 2 | 14.88 / 4.38 ms | 14.24 / 4.14 ms |
| 固定简拼与混合解释查询 | 140 × 2 | 52.86 / 33.84 ms | 46.17 / 26.09 ms |

两次重放均交换前后运行顺序，候选、结果和诊断计数零差异。组合改动数据同机与编译共享资源，因此时延用于解释热点。完整按键、冷热推理与调度配对另见 [Worker 报告](integration-round26-worker-isolation.md)。

## 活内存和可重放证据

`round26_input_probe.rs` 在单线程无窗口测试进程的全局分配器采集 Rust 请求大小。以事件前、后和请求字节峰值区分累计申请量与同时观察到的活字节。此口径覆盖该进程的 Rust 业务分配，排除分配器保留、系统私有提交、原生依赖及 realloc 调用内部瞬时重叠。图边数、展开数和驻留路径则来自搜索诊断。诊断运行独立重放各搜索阶段。真正的无探针逐键延迟以 Worker 配对组为准。

原始逐例阶段和差分文件在 Git 外 `.local/round26-baseline-phases`、`.local/round26-lexical-pairs`、`.local/round26-lexical-cached-pairs`。仅发布数值、身份和哈希。
