# Round 30 简拼候选格与可达性

比较起点为 Round 29 交付 `8c92ea0be4882d69dda97c3642d81b312ef811a7`。生产候选仍用 16,384 条图边、200,000 次展开和 50,000 条驻留路径。边的键、预算竞争顺序、代价和平局条件保持原约定。

## 三种逆向方案的小图比较

研究脚本 `.local/round30-graph/exhaustive_endpoints.py` 穷举 5 个节点的 1,024 个所有前向端点组合，每种图的同一端点有 3 条独立边，再各测 1、3、7、15、31 五种保留容量。直接递归枚举共得到 46,724 条完整路径和 38,320 条部分路径。该脚本用于比较图论性质，生产准入由 Rust 测试单独核验。

| 方案 | 实测探查与边界 |
| --- | --- |
| A 线性逆扫保留边 | 5,120 图全部与路径穷举一致，探查 39,998 条保留边。同端点上的平行词条分别探查 |
| B 发现边时递推后缀 | 可以继续用来指导边准入。与最终保留图比较，2,061 图发现到的后缀已被后续淘汰断开 |
| C 按终点逆向探查 | 最终保留图的 B 树以 `(end, entry)` 排序。同终点只查一次，遇到可达终点即停。5,120 图的判定全部与穷举一致，共探查 13,844 个端点。在同组图上若只保留能抵达完整终点的边，3,052 图会丢失从起点可达的部分路径 |

实际准入仍按 Round 29 的倒序起点和候选访问次序执行。预算触顶后，优先队列更新仅在桶排序键变化时执行。同代价代表弧更新仍写入候选弧序列。终点位图从准入后实际保留的边计算，PositionDag 使用该位图判定完整路径的边，候选格仍发布合法部分边。图边截断随结果披露，`guaranteed=false` 和原文回退保留。

## 可重放正确性证据

- `cargo test -p cloudleaf-search --test suffix_admission --locked --offline -- --nocapture` 在两个测试中验证了 67 次输入、来源、读音边界、弧顺序及编辑代价。无容量截断时逐条用独立音节弧枚举检查选中的弧和平分时的稳定顺序，并与 Reference 比较完整候选和分数。触顶合成用例另检查保留的部分边及截断状态。原始记录位于 `.local/round21-runs/round30-suffix-admission-full`。
- `retained_suffix_matches_exhaustive_paths_after_capacity_evictions` 使用真实 Rust 准入器输出的保留边，在 5,120 个小图逐位置递归校验终点可达性。覆盖了后续淘汰导致的后缀失效、仍有价值的部分边，以及第 512 位的合法边界。概念对照结果见 `.local/round21-runs/round30-suffix-study/stdout.txt`，SHA-256 为 `f606ab11262bd877ed5060097ffc9ed9302fd0690dfebd9babac2a74074eedb5`。

## 生产配对

### 全改动方案

首个候选合并了每查询根节点 Trie 转移缓存、连续音节弧偏移、处理栈复用、准入排名更新收敛和终点位图。该方案单独构建，评分器保持 Round 29。AB/BA 每轨执行两对，逐事件候选与回执相同，采样没有观察到已知竞争任务。

| 轨迹 | 每版样本 | 基线 P95 / P99 / 最大值 ms | 全改动 P95 / P99 / 最大值 ms | 分配次数 P95 |
| --- | ---: | --- | --- | --- |
| 171 键简拼 | 342 | 19.726 / 24.701 / 28.944 | 26.767 / 37.069 / 43.701 | 7,343 → 7,168 |
| 243 键简拼 | 486 | 25.450 / 32.443 / 37.902 | 29.728 / 41.365 / 49.095 | 12,512 → 12,226 |

243 键两个逐对插桩相交 P95 为 17.588→18.348、17.135→16.144 ms，方向不一致。243 键活字节增量 P95 由 2,766,188 到 2,776,512 字节。虽然分配次数减少，两轨无插桩尾延迟都回归，舍弃这一组合。

原始配对见 `.local/round30-graph-only-171`、`.local/round30-graph-only-243` 和同名 `-conditions.json`。构建回执在 `.local/round30-graph-build/summary.json`。首次探针链接返回 1，因为实验脚本传入了多余的 `-L`。原始错误保留在 `.local/round30-graph-build/link-input`，同一源码的修正链接分别返回 0。

### 收窄方案

收窄方案移除了根节点 Trie 转移缓存，保留连续音节弧偏移、处理栈复用、准入索引更新收敛和终点位图。触顶时按保留边数一次预留边、解释和出边索引的空间。评分函数沿用基线。该方案进入生产实现 `2d90d71c54e4e7e2cb1624bb3beea4d5bac4849c`。归档变种的 `schemes.rs` 与 `search.rs` SHA-256 分别为 `9a203b3312f93d0243455d69afbf0cbe186fd02095ce50eef351de234757398b` 和 `844fd6d026be4f325256372f6289278a4b139c8fdd49e2b14fca1e6e42c7fdcc`，与已提交的两个生产文件逐字节相同。

逐按键比较了候选帧、图边、展开、驻留路径、诊断、缓存状态和事务回执，收窄组在两版间均一致。171 键含事件 78、79，事件 79 的空格回执摘要 `628b0103f9bfafec58ca9b0c05b1fd310c342f6bfed10741d14322ae8033a694` 与基线相同。此处为整帧和事务投影对照，冻结目标及图边的逐条确认和最终分支回归见[延迟与兼容报告](integration-round30-latency.md)。

## 精确提交冻结回放

最终实现 `c5461c7ea160d872db82b0c514e7cbeff249bf36` 的音节弧遍历改用顺序不变的切片迭代。Git 归档构建的独立图探针逐项匹配 349 个未触顶样本的边、弧与完整候选摘要。52 个触顶样本仍产生完整候选，其中 7 个来自 171 键轨迹、45 个来自 243 键轨迹。原先未接通的 43 个图保留恢复路径。两个冻结目标在实际输入帧均排名第一，事件 79 获得空格 Applied 回执。

- 171 键：原按边逆扫 114,688 次，按保留终点探查 216 次。图证明摘要 SHA-256 为 `1355daba1f3c84005578a24a4733e0b72d0db4965b7073f3b060f6ff585d9fa5`。
- 243 键：原按边逆扫 737,280 次，按保留终点探查 1,674 次。图证明摘要 SHA-256 为 `e8722b5d0b323c9915942e8ecce01188a76105d1ccdcf8d113a93538e1d4ebba`。

探查次数来自相同保留图的独立结构计数，组合阶段的毫秒结果单列于延迟报告。最终输出目录为 `.local/round30-search-product-final-graph`，初版原始证据仍在 `.local/round30-search-product-graph`。
