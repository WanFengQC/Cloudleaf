# Unihan17 隔离读音逐条审计

固定原件、源码音节摘要和每个相关属性的原始行号见[JSON证据](cl009/unihan-reading-audit.json)。本表中的原始数据派生自Unicode17，仍遵循Unicode-3.0许可，许可原文见`data/licenses/Unicode-3.0.txt`；审计文字和工具源码为项目编写。

依据[UAX38 revision39](https://www.unicode.org/reports/tr38/tr38-39.html#kMandarin)，kMandarin是面向CLDR排序/转写的常用拼音读音，可能不完全追踪部分词典的偏好。字段合法不等于本产品已决定采纳其输入键编码；缺少频率，不能推断常用程度。

全部18条都符合该版kMandarin的NFD语法。7条是成音鼻音/叹词组，11条是当前自编表未登记的字母音串；不是18条源坏记录。本轮不修改Rust/Python生产音节表，不做近似替代。17个字符因此缺少运行时读音；嗯仍有源中另一个ēn→en读音。
