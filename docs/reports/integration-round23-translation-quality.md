## 对照及边界

| 对照 | 实际行为 |
| --- | --- |
| ct01 两个金额互换、ct02 数字/商品绑定互换 | 金额或单位的数值多重集保持一致，规则漏报关系错误。 |
| ct03 否定漏译 | 规则无否定语义，未触发告警。 |
| ct04 出发和回程日期互换 | 日期各自为等价格式，规则漏报事件绑定。 |
| ct05 大小关系颠倒 | 单位和数值逐一存在，规则漏报比较关系。 |
| ct06 两个术语的主语、宾语角色互换 | 术语逐一出现，规则漏报关系。 |
| ct07 日期和单位等价、ct08 币种等价 | 两条均保留为等价表示，未触发复核。 |
| ct09 货币与品牌变化 | 告警金额变化及术语缺失。 |
| ct10 `$12`、ct11 `03/04/2026` | 符号或日期语义仍歧义，触发复核。 |
| ct12 中文数字单位等价 | 中文数词不在现行十进制输入规则内，两项等价度量进入人工不可核验提示。 |

六条预置关联错误均漏报，三条预置歧义或表面变化均提示复核。三个等价对照中，一个触发保守复核。模型真实样本的例子和这些控制对照不支持估算生产误报率、漏报率或质量分数。完整性提示继续只用于复核，原始输出没有自动替换，也没有作为翻译优劣的自动准入。

复验使用现有 release 的 `cloudleaf-translation-ipc` 与 `cloudleaf-translation-integrity`，用 Rust 1.90、Edition 2024 编译探针，通过兄弟程序解析和私有管道约束运行。原始命令、每条输出、模型阶段、程序及 fixture SHA 保存在 `.local/round23-translation-verified/{run.json,stdout.tsv,stderr.txt,exit.txt}`，首轮未含固定复现的证据仍保留于 `.local/round23-translation-research`。模型继续为 `research_only`，正式中英翻译质量指标保持未测。
