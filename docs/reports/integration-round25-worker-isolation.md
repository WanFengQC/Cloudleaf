状态为 partial。以下结果使用实际授权的固定 Marian 权重及 Windows 无窗口探针。窗口、TSF 和长测均未执行。

## 实际修改

- 离线工作进程在握手后持有一份定额 Marian Rayon 池。切换翻译方向时先释放模型，后校验、加载新模型，在同一个池执行计算。相同方向保持原来的热模型复用。请求队列上限、取消、generation、任务编号、输入和结果版本的协议保持。
- `WorkerConfig::sibling_auto` 根据当前可用逻辑 CPU 数选择 1 或 2。少于 6 个时选 1。既有显式档可指定 1、2 或 4。Windows 可显式通过进程创建标志把受监督的工作进程置于低于正常的优先级。现有正常调度仍为默认，Linux 显式设置 Windows 策略会被拒绝。
- IPC 先绑定已验证的本地模型 catalog、环境线程档和实际推理返回的池大小。锁定的 Candle CPU 读取启动时设好的线程数，小算子走串行，大 GEMM 的 Rayon 迭代在本池执行。单元测试在三档线程池运行实际 256×256 CPU 矩阵乘法，并确认复用句柄前后线程身份一致。
- 探针从实际 Win32 物理核心关系和允许掩码选择整核，核对父 PID、宿主和 worker 的生效掩码，并验证每个已观测输入端点都落在分配的宿主核心。实验仅约束本次启动的两个无窗口进程，没修改系统设置。低优先级进程核对实际创建类。
