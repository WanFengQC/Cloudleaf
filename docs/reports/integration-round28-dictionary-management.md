# Round 28 词典与用户词库

状态 `partial`。当前资源页为基础及补充词典各保留一个只读核验槽。显式输入绝对路径和全量 SHA-256 后，后台使用输入引擎实际的 schema 2 reader 检查词条结构、内容身份、大小和记录声明的来源。文件上限 32 MiB。核验失败保留上一次核验成功的身份，并同时报告本次失败。声明来源用于排查，许可证据仍来自版本锁及既有发布验证器。

- 面板上的核验证明文件可被现有 reader 解析。宿主存活回执另行显示当前活动快照身份。现有发布管线可校验批准版本的清单、当前指针及历史回退。基础和补充词典分别热加载、切换和回滚的产品入口尚为 `not-implemented`。
- 用户词库仍经既有 Rust store 的版本检查和后台操作，支持增删改、导入、导出、备份、恢复、关闭学习和清理学习记录。资源页显示当前查看目录的状态、代次、条数和错误。用户词库部署中保持独立，发行演练只迁移已发布的代次。
- `tests/controller.rs` 覆盖两个槽独立通过或拒绝、同槽失败保留上一次通过身份，以及资源核验与翻译结果隔离。无正式词频的记录继续保持 `unknown`。
