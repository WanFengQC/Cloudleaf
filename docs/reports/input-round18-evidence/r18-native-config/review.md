- `tests-only.patch`先添加真实Host控制器测试：保留原文/光标、方案修订后旧候选拒绝、NotApplied/Unknown禁止切换、第二引擎预检失败时第一引擎不变、多页数字选择。

源码复核：双引擎均预检后才更改；更新仅调用纯Rust核心、无外部消息循环或异步回调。候选ID/修订继续由实际InputEngine核验，旧方案点击不会因epoch未变化而获准提交。未知提交仍被Host quarantine阻止设置；发生意外双引擎不一致时隔离且不写文档。

本子任务未编译或运行UI，遵守主代理正在执行native、Clippy和差分时不并行重测的要求；真实红绿、全回归、K10预算及窗口输入由主代理保存。不能把临时补丁等同验收通过。

物理键盘入口仍只接受ASCII字母/撇号，v表示ü。纯方案解释API可直接规范化ü并保留UTF-8字节范围，但原输入核心光标/退格仍按ASCII处理，未扩大本轮改为任意Unicode组合输入。
