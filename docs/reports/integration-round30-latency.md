## 评分消融

评分延迟物化试验只替换 `Scorer::extend`，沿用原图、输入及候选排序。普通 Release 每条轨迹各四对。171 键每侧 684 事件，P95/P99/Max 为 21.428/27.091/34.910 → 22.341/30.793/42.708 ms。243 键每侧 972 事件，为 28.904/35.855/47.912 → 25.981/33.914/54.872 ms。两条轨迹都只有 2/4 对的 P95 改善，候选和提交回执一致。243 键最高样本是 long-1 事件 26，15,481 边、146,701 次展开、81 驻留，无截断，同对基线为 23.010 ms。独立的历史插桩显示该事件遍历 30.052 ms、其中评分 23.362 ms、相交 10.574 ms。试验收益没有在两条轨迹重现，原评分器保留。证据位于 `.local/round30-position-pairs-ordinary`。
