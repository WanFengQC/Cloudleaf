# Round 29 兼容性与发行

## 继承边界

混排仍默认关闭，用户词库与学习沿用既有代次、稳定用户条目 ID 和已确认提交语义。固定研究翻译模型与词典的来源审批各自有效。语义词性、正式准确率、正式频率和模型分发需要相应证据。

## 发行范围

`config/language-resources.json` 记录固定基础与研究补充资源的版本、原始资料、规范运行文件和许可 SHA-256。`tools/release_stage.py stamp-dictionaries` 绑定实际包内文件、来源和许可原文。已审查的同一版本基础资源能够随隔离包验证，研究补充资源拒绝作为发行词典入包，默认关闭。CI ZIP 提供来源登记和许可，词典内容与模型权重留在本地。

批准过的历史注册表条目仍可用于回滚。用户的资源选项随已有隔离迁移路径复制，用户词库代次留在私有配置目录之外的独立词库持久化目录。包中登记用户库为外部资源，版本来自在运行的宿主回执。签名维持 `unsigned`。正式系统安装、系统输入法注册和卸载均为 `not-run`。

`.local/round21-runs/round29-release-final-corrected` 的发行验证覆盖许可与源锁整对、已审历史清单、用户资料迁移以及仅改文件后缀不能使词库入包。真实固定基础词典的临时封装通过，真实补充层被拒绝，记录在 `.local/round29-release-assets-fixed`。完整回归与实际 CI 独立绑定。
