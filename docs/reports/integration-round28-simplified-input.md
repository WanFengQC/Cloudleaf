# Round 28 简拼候选格与资源

## 实现与边界

设计见 `docs/integration-round28-search-design.md`。基线是 Round 27 最终源码 `a5675b0e88fb4ea9f0e88061350f4a255beb98c5`。

- `schemes.rs` 让相交图接管解释器已有的音节弧。边只记录代价和连续索引池的范围，评分直接读取代价，查看候选来源时按旧顺序生成完整解释并复用。构图遍历、状态去重、候选边和搜索预算沿用原顺序。
- `lexicon.rs`、`lattice.rs`、`layer.rs` 与 `schemes.rs` 使用同一位集合存储规范音节边界。词典入口持有 80 字节上限，Trie 状态只沿已验证的拼音扩展。边界位集合比较保留同拼写多分段、分隔符和用户词表 Trie 行为。
- 新增搜索回归用实际简拼格验证输出的原音节边界、边代价、按需且单次生成解释。已有的方案、引用、用户层、资源和差分测试均保留。
- `tools/performance/round28_search_replay.py` 使用同一工具分别构建基线和候选，在相同词表、模型、设置与预算下核对逐事件公开输出、候选身份、搜索统计和提交回执，并重放两个有标注的位置。按键计时、分配和分阶段剖析用独立运行。

## 截断与同预算可达性

默认图边 16,384、展开 200,000、驻留路径 50,000。边身份为起点、终点、词条 ID。对于同一身份，保留最小的代价与弧次序代表。状态去重以终点、Trie 节点、编辑数及规范边界为键。同目标 Trie 节点但音节边界不同的状态可以匹配不同词条，保留为独立状态。词典拼音完整匹配后先做边界核验，再合并等价来源，最后对首次出现的合法身份扣除边预算。当前起点已扣预算的合法边照常发布。

Round 27 精确源码与本轮实现的 52 个截断诊断逐字段一致。每次已处理词条由边界不匹配、重复来源、16,384 条已接受唯一边和 1 条因预算被拒绝的合法边组成。重复来源已在扣予边预算前消除，位集合和解释惰性构造仍为每个唯一身份扣除一条。合计 43 个截断图缺少完整可行路径。
