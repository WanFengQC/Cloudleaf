# Round 27 自动中英混排

自动混排可在现有输入核心显式启用，默认关闭。系统先保全可辨认的邮箱、URL、代码等字面输入，再用固定词典的完整读音端点判断可能的中文区间。中文区间正常选词，英文保留实际字节。启用与关闭仍由现有修订、回执和学习凭据约束。设置读取及入口连接另见本轮设置证据。

## 回归与修复

- 新增 `crates/cloudleaf-input/src/mixed.rs`、冻结轨迹、七项特定场景回归，以及只输出事件编号、候选秩和诊断统计的 `mixed_input_trace` 示例。
- 自动混排支持候选、光标移动、退格和连续删除、原文提交、数字正文及显式候选数字选择。提交成功后只产生中文词条的学习证据。显式原文、失败和不确定提交保留原有保护。
- 首次固定真实词典回放暴露专名被内部的短拼音吞掉的缺陷。机械词典加入合法的短拼音同音词后复现，返回码 101。修复仅要求紧随单个大写字母的短中文区间具备与普通小写边界相同的长度证据；紧邻缩写或数字的规则仍适用。原样回退一直可用。
- 同一个冻结集由首选 13/16、Top10 14/16 改为首选 14/16、Top10 15/16。其中专名样本从 Top10 外进入首选，其余各例秩不变。独立英语、缩写、数字、网址、邮箱、标识符、代码、句号和冒号覆盖在分母内。小写 `meeting` 目标在第 7 位，小写 `check` 目标仍未进入 Top10。这两条仍需更可靠的英文片段识别、词条覆盖与排序证据。混排保持 opt-in。
