# Round 22 翻译关键语义保护

规则实现为 `done`，正式语言质量与原生窗口验收分别为 `blocked` 和 `not-run/user-paused`。整合源码、真实 worker 回归和最终 Windows/Linux CI 的精确提交以本轮总状态和本地回执为准。

## 检查范围

`cloudleaf-translation-integrity` 仅依赖 Rust 标准库。它比较原文与模型原始输出中的类型、规范值、出现次数和原始 UTF-8 范围。原始译文与显示译文一致，修改记录为空。检查不会执行换汇、单位换算、术语替换或原文改写。

| 内容 | 规则和结果 |
| --- | --- |
| 数字与百分比 | 支持十进制整数、小数、前导零、千位分组、全角数字、常见正负号和英文序数。规范值按字符串比较，保留重复项。科学计数、分数和形似其他 locale 的小数分隔标为无法确认。 |
| 金额 | 区分金额与普通数值，识别中英常见币种代码、明确币名和符号。`123.45元` 与 `CNY 123.45` 等价，`USD 123.45` 与 `$123.45` 都不保留已明确的人民币。原文 `$` 未确定美元币种时标为歧义。无法证明含义的会计括号及冲突币种标为无法确认。 |
| 日期与时间 | 规范化中英完整公历日期及常用本地 12/24 小时时间。`2026年11月25日` 与 `November 25, 2026` 等价。含歧义的月日顺序、无效日期和部分时区表达需人工确认。 |
| 单位 | 支持范围限定在已登记的温度、长度、重量和容量记法。`12.5 公斤` 与 `12.5 kg` 等价，`100厘米` 与 `1 meter` 标为变化。单位剥落不会因数值相同而通过。 |
| 术语 | 术语来源只接受可验证的用户显式配置。支持分方向启用、原样保留、指定预期译法、区分大小写或允许 ASCII 大小写变化。词边界检查防止匹配更长 ASCII 标识符中的片段。相同位置优先匹配最长源术语。单个目标片段不能证明两个源片段均被保留。术语规则不能掩盖冲突的独立金额、日期等事实。 |
| 截断 | 已知缺少 EOS 且达到生成限额时，真实 worker 返回 `OutputTruncated`，宿主保留原文并拒绝确认。完整性类型也能接收可信的截断标记。规则不靠标点或文字长度猜测截断。 |

高风险状态包括 `Missing`、`Changed`、`Ambiguous` 和 `Unverifiable`。确认逻辑必须关联当前结果版本及请求身份，用户审阅后仍需显式发起提交。

## 术语配置

文件使用 UTF-8 TSV。首行为 `cloudleaf-glossary<TAB>1<TAB><术语版本>`。后续每行依次包含方向 `zh-en` 或 `en-zh`、启用 `true` 或 `false`、大小写 `sensitive` 或 `ascii-insensitive`、源词、动作 `preserve` 或 `translate` 和目标。`preserve` 的目标列为空。`translate` 的目标列为用户期待的译法。

配置上限为 32 KiB、128 条及单个术语 128 UTF-8 字节。重复启用或大小写策略冲突按方向拒绝，错误定位到条目编号。未显式配置时默认术语表为空，研发展示用词只存在于测试样本中。术语表与拼音用户词库分离，原文、译文和私人术语不会从完整性报告记录或上传。

## 可重放研发结果

沿用 Round 21 `dev-zh-03` 样本，Round 22 最终双进程实验在 3 次方向切换后生成相同的原始输出。原文为「2026年11月2日，Cloudleaf 发布了第13轮研发计划，预算为123.45元。」模型输出如下。

> On 2 November 2026, Claudelaf released the 13th round of R & D with a budget of $123.45.

语义检查将日期和 `13th` 识别为等价表达，明确标出货币变化以及配置的 `Cloudleaf` 术语缺失。原始样本及来源身份仍见[上一轮推理摘要](integration-round21-evidence/round21-real-models/summary.json)。

定向 Rust 1.90 测试共 11 项。首轮运行保留全角日期和英文序数两项失败。修正后测试覆盖重复数值、额外值、明确币种及符号歧义、闰日和无效日期、百分比、四类单位、术语边界、大小写、方向、冲突以及已知截断。原始命令输出留在 `.local/round22-integrity-red/tests.log` 和 `.local/round22-integrity-green/tests.log`。

## 质量边界

人工独立金标准尚未交付，因此没有产品级误报率、漏报率或翻译准确率。新增输出中的孤立数值会提示核对，可能包含译文为清晰起见添加的序号。术语依赖用户配置，未配置的专有名称或中文大写数词可能漏报。规则不能判断数值与哪个人物、商品或事件对应。地区自定义表示、复杂时区、单位和日期约定需进一步独立评测。模型保持 `research_only`，Top-1、Top-5、MRR 保持 `null`。
