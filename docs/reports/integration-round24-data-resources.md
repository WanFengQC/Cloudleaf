# Round 24 中文语言资源与统计对照

同一固定训练片段分别构建确定性最少词元基线和观察词面概率分词。本轮两者使用同一个模型格式与严格 reader。原始资料、逐词计数及模型留在 Git 外。

概率分词先在训练正文中统计词表各词面的实际出现位置。多词面重叠可以各记一次，同一个词面不会因多条读音重复计数。`Q(w)=(C(w)+1)/(Σ C + |V_seen| + 1)`，分母中最后一项保留给单字 `unknown`。动态规划先最小化未覆盖字符数，再最小化整条分词路径的定点负对数和、词元数，平局优先左侧长词。对数采用与 Rust 兼容的整数 1024 单位。选定的分词路径重新计数一元、BOS/EOS 和相邻关系。词面重叠计数、条件分词计数和生产频率分别记录，软估计没有实现。

若实际模型行数超过既有预算，将低频词面完整映射至 `unknown`，保留原始计数，避免破坏原格式对一元和相邻计数的流量守恒验证。只对研究快照执行，既有词典和存储边界不变。

## 新研发验证

以固定盐按 SHA 排序，在同一 Tatoeba 已冻结开发分区选 40 个新家族。排除 Round 16 已用任务和 Round 23 固定 40 个任务的家族、正文 SHA、句 ID 及近重复，排除与既有中文维基新闻开发行和组内的近重复。NFKC 规范化正文完全相同视为重合。长度至少 8 个标量的文本用三元字片 Jaccard ≥ 4/5 检查。实际训练片段复核后，40 行与训练家族、完全相同正文和近重复三者的重合均为 0。选择先于拼音映射。固定补充词典导出的同一份拼音用于两个词典和所有算法对照，共 40/40 可映射，零超长。未读取正式 heldout。原任务记录 SHA `58fd5878e01ab851972039d35fd59b5f1a87cf60b469fed332810b64a60cd614`，排序输入 TSV SHA `b81911d618c013682dab44ee8ea87daa0a01270bee6ff6353f567c24cab63603`。仍共享 Tatoeba 全球来源，未核验跨语言改写语义重合。拼音由词典派生，范围是同来源研发回归。
