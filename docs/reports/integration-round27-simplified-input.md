## 修改与反例

简拼首字母、完整音节和末尾前缀与词典 Trie 相交后，可由多条解释命中同一终点和词条。构图按起点、终点、词条合并等价的边，保留原代价、词条边界及弧次序决定的代表。触及第 16,385 条不同的候选边时，旧实现跳过了当前起点的全部已收集边。

修复后发布当前起点已经占用预算的边和解释证据。下一个超预算边仍拒绝，以 `GraphEdges` 报告不完整。相交状态改用内联边界及弧索引，减少短序列分配。仅当编辑预算为零时，PositionDag 直接使用已有位置桶。触顶且无边能到达输入末端时，所有搜索方法都可跳过已证明无法生成完整候选的展开。

改动保留 16,384 图边、200,000 展开、50,000 驻留路径及原输入边界，默认排序、用户词优先、候选身份和提交事务沿用原契约。候选格部分结果仍限诊断，输入核心在预算失败时保全原文。
