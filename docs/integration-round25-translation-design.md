# Round 25 翻译完整性约定

沿用 Round 24 的固定 Marian 权重、worker 协议和原始译文。检查结果只用于复核，用户确认仍绑定当前源文本、任务身份和结果版本。复用既有错误分级和 UTF-8 字节跨度，无默认网络及模型下载。

## 数值与时间

保持既有阿拉伯数字、区域歧义、日期和币种边界。限域解析两位以内的中英整数。在受支持的单位或明确数量语法里比较数值，避免把单独的英语代词或汉字词素当作事实。接受明确 AM/PM 的整点和点号分钟格式，并复用原时间与时区判断。无 AM/PM 的点号保持小数语义。

## 结构线索

- 只在完整的多句输入上比较显式句末边界。短写、小数及 URL 中的点须排除。源句数大于目标句数时提示无法确认，合法合并句子仍可能触发。不得据此断言漏译或声称句子已准确对齐。
- 条件、后续与分支使用有限中英显式标记。缺失的标记或未保留的显式条件对象给出无法确认，不推导逻辑等价。
- 显式命令中的同一动作组反转提示疑似错误。保持否定范围仍需人工审核。直接设置同一 ASCII 标识为相反的开关值可以确认变化。没有稳定对象或可识别动作时保留未确认，不自动分配角色。
- 两侧均存在独立、无歧义的标签和数量事实时按标签核对，不以数值的顺序作对应。两侧数量的多重集相同却有显式标签数值变化时提供范围证据。复用现有数字、单位解析。复杂名词、自然人身份或无明示标签的单位交换仍不作自动推断。

用旧实现可复现的对照测试验证每项边界。标记规则全部作用于原始字节范围，保留已有原文、告警、根据及对照版本。Round 23、24 原始输出与新固定开发样本分别回放，后者冻结后保留新旧检查，以及构造的错误、等价和非等价分母。真实推理输出仅存 Git 外。未实施模型后端切换或使用额外权重。正式质量仍须独立双语审校。
