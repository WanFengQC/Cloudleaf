## 研发数据与人工边界

另一独立真实来源先核原发布者/原文许可、版本、署名/例外、隐私、大小和领域，再受控取得固定原件；查看候选前冻结样本/文章家族/抽样规则和dev/heldout。全文/片段与既有训练做重复及明确近重复标准隔离；不擅自采个人聊天，不从待测词典生成正确答案。可由词典自动导出研发拼音，但必须标记依赖和多音歧义，人工确认/允许答案保持null。无独立人工gold，正式Top1/Top5/MRR仍null。

## 隔离交互与测量契约

入口显式使用预校验词典/模型，正常启动默认行为不变。键入、退格、修订、分页、Space/数字/Enter/Escape、焦点与鼠标候选走实际核心。实际Host两个引擎必须语义一致，选词校验当前revision和candidate ID；确认写入owned文档后才发送CommitSucceeded。Unknown不自动重试，不重复上屏；隔离旧请求/上下文后才能新会话。普通窗口不获取TSF manager/profile，不调用注册服务。

测量分开记录实际核心执行、投影执行、帧生成、候选窗口更新和隔离文档事务；未创建窗口时UI阶段为not-run。隔离Host/组件回归不等于真实系统应用验收。跨事件取消仍未实现，底层合作式API与工作预算不冒称同步线程可抢占；本轮不为功能列表引入无界线程或无收益增量缓存。

实际窗口检查发现当前系统IME拦截测试窗口的ASCII按键，另有EDIT持焦点时父窗收不到WM_KILLFOCUS。隔离入口改为按顶层WM_ACTIVATE处理整窗失活；仅对本入口创建的父子HWND解除继承的IMM上下文，使用固定windows绑定的`Win32_UI_Input_Ime`功能，不改系统键盘布局/配置或注册服务。通过真实WndProc回归证明失活保全，并检查本窗口及子控件无IMM上下文；现有生产TSF入口不调用此操作。
