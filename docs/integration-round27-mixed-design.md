# Round 27 自动中英混排设计

混排按会话显式启用。已有全拼、简拼、双拼和显式原文提交沿用旧入口及帧契约。资源与识别都在本地。全部识别以用户实际输入的 ASCII 字节为依据。切换时保留原文与光标，刷新候选和修订；待确认和已知失败的提交须先处置。

## 解释和边界

独立文字片段保留大小写、数字与符号。邮箱、URL、路径和有明确界符的代码优先按字面保全。遇到这一类证据时保留整段字面内容。英文片段判断采用确定性字形及相邻中文完整词条证据，不引入新的英语词库或语料。连续大小写和数字提供字面线索，小写外语须有足够长度，禁止从字面内容剥离次要短音节。中文段使用现有只读 Trie 识别精确可覆盖区间，再复用正常候选引擎。词条端点只记录有无，不复制同音桶。规则不保证识别词形恰好属于拼音的英语，原文始终可显式提交。小写歧义保留原文候选。

既有 64 字节上限同时限制规划。混合解释至多三段中文，分段搜索总图边和展开量使用原配置总额度，峰值驻留限制沿用。任一中文段无候选、预算终止或保真条件不足时，保留整段原文。混排候选的确定性序由各中文分段的既有排序组合。全中文候选沿用原来查询与身份。跨键缓存不依赖混排内容。

## 光标与提交

字面点号、冒号及代码符号留在组合，允许后续 URL、邮箱和代码界符识别。纯中文句点和冒号可在候选中显示全角形式并确认；明确的纯中文逗号、问号、感叹号和分号仍可触发即时提交。普通空格可在字面结尾留下空格，回车按当前候选确认。纯数字、字面及混排组合支持原地光标、退格、连删和 Esc。混排启用后默认将数字解释为正文，显式导航至候选后才按当前页编号选择，输入编辑后恢复数字正文。宿主需沿用预判与实际处理的一致性，组合及失败事务不绕过回执。

新候选身份使用当前原文和已选中文分段的实际路径身份。提交成功之前仅保留中文词条证据，字面片段没有学习词条。原文候选、失败或未知提交不学习。

## 修改与验收

修改平台无关输入状态机、其后端分段调用和只读词典端点接口。冻结自主编写的混排用例，回放相邻中英、缩写、数字、URL、邮箱和标识符，验证原文、候选身份、修订、局部编辑、数字选择、提交失败及学习凭据。在原默认关闭路径上复跑历史测试。小写歧义和缺资源场景保留到误识别报告。真实桌面与正式语言质量独立记账。
