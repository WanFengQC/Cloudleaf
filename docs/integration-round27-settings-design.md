# Round 27 统一设置中心设计

整合工作区 Round 26 基线为 `a6e48cbe28d48a010629a65537cfb6743522356a`。独立翻译面板保留 Windows 凭据名称空间和 schema 3 原文件。设置中心读取同目录的 `input-settings.json` 管理输入设置。输入设置只包含方案、模糊音、纠错、自动混排和候选数，与翻译模型、授权和词库的数据生命周期分别提交。安装、TSF 与真实桌面流程不在本轮启动。

## 输入配置

用轻量 `cloudleaf-settings` 定义 schema 1 输入偏好，与平台无关的核心使用相同校验与构造逻辑。配置允许标准全拼、简拼及小鹤双拼。模糊音每组仅一次，纠错沿用核心方案规则。页数与最大候选数分别验证，混排初始关闭。设置中心通过后台读写切换编辑和回执状态，控制器与隔离宿主使用同一设置契约。输入调用路径仅使用内存配置，故障时返回有效备份或默认值并保留原件。保存核对当前 revision，在同一目录写入临时文件并原子替换，旧有效副本进入备份。未采用物理断电验收推断。当前组合正在编辑或存在提交事务时，宿主保持原输入并等待显式重载或下次启动。

## 翻译与上下文

沿用 schema 3 解析和旧 schema 1/2 迁移。新增可选 Worker 线程及进程档位，缺省保留单线程和正常优先级。Windows 研究档由已有 Worker 客户端设置进程优先级，禁止保存 CPU 掩码。正常联网权限只在当前会话生效，授权仍按请求绑定；密钥由现有系统凭据命名空间保存。在后台准备并校验候选设置，保存失败保留当前服务及配置。只有旧 Worker 确认停止后启用新 Worker，不在设置切换时重复启动现有模型。模型 catalog 内容 SHA 与方向、模型进程状态按真实可观察信息展示，模型文件完全校验沿用首次翻译任务。

Win32 保留原翻译工作区及在线授权，在同一窗口增加输入设置页及应用回执。输入、资源和译文状态只展示原有或本轮启用的功能。词库操作优先复用现有权限、校验及备份实现。语言资源如果当前入口未加载，不显示镜像状态。冻结交互回放覆盖 profile 首次加载、保存、旧文件兼容、损坏回退、无效组合拒绝、防止保存失败破坏提供者、取消及凭据无明文。设置面板仅执行构建和无窗口测试。
