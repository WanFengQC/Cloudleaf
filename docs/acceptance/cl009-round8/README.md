## 来源采用决定与现代统计

[source-decisions.md](source-decisions.md)逐源列本轮采用决定。[Google候选核对](google-books-2019-review.md)记录本轮真正新增的官方bulk许可出处；没有下载任何分区，仍没有生产频率。

|指标|正式交付必须明确|禁止替代|
|---|---|---|
|token frequency|实际token计数/同版本同范围总tokens，固定分词/筛选协议；缺测为unknown/null|DF、行序、单字频率、Viewer平滑比例|
|document frequency|包含词条的不同文档/书籍数及总文档数、文档边界和跨年去重口径|token occurrence计数；跨年随意求和当独立书籍数|
|Zipf|同词同源正token比例的`log10(p)+9`或有原生定义摘要的值|从DF或零/缺失token观测推导|

书面Ngram候选不是现代口语输入分布；频率合法性、单位、完整性、代表性与算法效果分别验收。现正式词条包123,544条runtime、1,468条隔离和unknown均不变。
