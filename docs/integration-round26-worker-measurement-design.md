# Round 26 无窗口并发验证约定

基线使用 Round 25 的固定探针、离线 Worker 和运行时词典身份。现有 171 键与 243 键轨迹分别计量，保留两种输入排序和同配置的候选行为差分。普通输入与译文原件及过程采样保存在 Git 外。报告仅保留计数、分位数和证据哈希。

- 每一比较档包含同策略的空闲组。使用相同机器、固定资源及三次交替重放，依次观察单线程正常、单线程低优先级、自动线程、自动线程低优先级和当前拓扑支持的整核隔离。调度修改只作用于已核验归属的测试子进程。整核隔离由可用完整物理核心、逻辑线程及核类别确定，其他拓扑保留无亲和性运行。
- 加载、就绪、热推理、用户词库写入、队列满、取消、方向切换和进程退出各有独立生命周期观察。并发推理与加载指标按每次按键完整落入的真实计算窗口统计，另外保留所有按键和没有重合的样本分母。
- 校验旧新候选、路径预算诊断及真实译文身份。保留退出状态、候选差异、进程策略和资源读回、实际推理窗口、队列及取消时间和固定资源与二进制的 SHA-256。
- Windows 进程内存和线程 CPU 计数来自普通权限探针。调度等待、ETW、缓存失误和 DRAM 归因只有在可直接验证时报告。线程周期、墙钟与量化 CPU 各自保留。

真实窗口保持暂停。共享机器有构建或其他负载时，相关数据单独标为功能或诊断样本。单次开发机通过不会解除真实 Windows 产品门禁。
