# M1/M2 任务记录

记录日期：2026-10-22。设计输入为五份基线文档；具体接口与行为以 `m1-m2-design.md` 为补充。本次仅初始化独立本地 Git 仓库，尚未创建提交或配置远程，因此相关提交统一记为“未提交工作树”，源码指纹见实测 JSON。

## 共同行为与验收口径

以下条目共同适用：代码及项目手写数据采用 MIT；无新增第三方 Rust 库或第三方数据。实时核心不访问网络/文件系统、不记录输入历史、不输出日志；错误只含固定说明、代码与可选行号。Python 与工具链仅用于开发。每项的依赖、许可和隐私影响均依此规则，例外必须单独登记。

M1 目标是可重复构建、公共类型和质量门禁；不实现平台输入法或设置 GUI。M2 目标是有固定语料与实测的输入原型；不实现 TSF、生产词库、学习、异步翻译或整句词条拼接。所有任务完成记录均指本地交付；远程 CI 仅配置，尚未触发，Windows 真实应用验收属于 M3。
