## 资源生命周期

基础、补充与用户词库分别记录身份。基础与补充词典沿用 schema 2，采用相同 SHA-256 与许可证来源锁校验。允许启用的研究补充词库需要显式选择，默认关闭。基础及补充的旧版本分别可回退。背景线程准备不可变快照，先校验数据和模型绑定，再通过隔离 Windows 宿主的双核心预检。宿主在组合与提交清空后原子切换并推进输入修订。旧候选、释义及翻译按会话与修订失效。Unknown 保持原提交隔离。用户词库保留独立持久化、generation 与学习。各宿主回执独立标记待应用和已生效身份。

资源入口沿用设置目录与现有原子保存模式。文件持久化、资源准备、宿主应用是三个确认阶段。许可与清单通过发布工具验证，禁止从用户配置的自声明提升许可范围。正式发行资源声明列出各角色、处理后的内容 SHA、来源与许可证及包内范围。独立研究补充层的原件保留在包外；用户词库 generation 只来自运行宿主。
