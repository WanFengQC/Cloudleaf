# M2 原型数据

`dictionaries/prototype.tsv` 是项目为核心测试独立编写的 64 条微型全拼词典，包括少量同音字、常用短语、歧义读音、翻页候选和一条重复文本。它不是完整汉语词库，词频是用于验收排序的人工整数，不代表真实语料统计。

所有条目、英文测试注释和词频由本项目手工整理，未导入第三方词库或输入法数据。数据按项目根目录 `LICENSE` 的 MIT 许可证提供；正式词典、双语释义、模型或第三方数据需在后续阶段单独审核来源与授权。原型中的英文注释用于验证字段隔离，不表示 M4 双语词典已完成。

## 格式 v1

文件采用 UTF-8、LF 换行；读取器同时接受 CRLF。第一行必须是 `# cloudleaf-dictionary-v1`，第二行必须是以下六列，以制表符分隔：

```text
id    pinyin    text    frequency    annotation    source
```

`id` 是文件内唯一且稳定的词条标识；`pinyin` 是以单个空格分隔的小写完整拼音音节，`v` 表示 `n/l` 后的 `ü`；`text` 是提交文本；`frequency` 是 `u32` 范围的非负十进制整数；`annotation` 可以为空；`source` 是可追溯的来源标识。文件不支持字段转义，文本与注释不得包含制表符、换行、控制字符和首尾空白。

载入限制：文件最多 16 MiB、100000 个条目；每条最多 16 个音节且拼音字段最多 64 字节；文本最多 64 个 Unicode 字符，注释最多 256 个；ID 和 source 为 1 至 64 字节的 ASCII 字母、数字或 `-_.:`。任何坏行、重复 ID、未知音节或未知格式版本都会拒绝整个文件，并返回固定错误说明与行号，不回显词条内容。

词典在载入时建立全音节精确索引和最后音节的非空前缀索引。每个索引桶按词频降序、文本字数降序、稳定 ID 升序排序，并按提交文本去重保留最佳条目。查询要求音节数相同，前缀匹配仅作用于最后音节。显式分隔符后的空音节（如 `xi'`）不查询候选。

候选生成时完整匹配排在前缀匹配之前，再沿用桶内排序规则；跨分段重复文本也只保留最佳条目。按键查询使用有界的桶前缀读取，不重新读取文件、扫描整份词典或执行网络请求。候选注释不参与得分或提交文本。

## 版本与校验

`manifests/prototype-v1.json` 记录数据来源、许可证、条目数及原始 UTF-8 文件的 SHA-256。修改数据时应一起更新清单并重跑固定输入语料；不要只更新哈希以掩盖未经审查的候选变化。
